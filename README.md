# UiComponentLibrary

ASP.NET Core MVC／Razor Pages 的 Bootstrap 5 表單元件庫。

## 專案

- `UiComponentLibrary.Components`：可封裝成 NuGet 的 Razor Class Library。
- `UiComponentLibrary`：MVC 示範站與日後的選色、程式碼產生器。
- `UiComponentLibrary.Tests`：元件測試專案。
- `local-nuget`：本機套件來源；執行 `dotnet pack` 後輸出 `.nupkg` 至此。

## 目前元件

`ui-text-input`、`ui-textarea`、`ui-select`、`ui-checkbox`、`ui-radio`、`ui-button`。
